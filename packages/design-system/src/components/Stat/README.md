# Stat

A labelled figure: a small label over a large number.

```tsx
import { Stat } from '@fm/design-system'
```

## Props

| Prop        | Type        |                 |
| ----------- | ----------- | --------------- |
| `className` | `string`    | Extra classes.  |
| `…`         | `div props` | Passed through. |

## Do

- Group stats in a row; the figures use tabular numerals.

## Don't

- Don't put sentences in a stat.
