# Swatch

A square of a position band's colour, for a table's key.

```tsx
import { Swatch } from '@fm/design-system'
```

## Props

| Prop        | Type         |                                                                          |
| ----------- | ------------ | ------------------------------------------------------------------------ |
| `className` | `string`     | The band: `is-champion`, `is-ucl`, `is-uel`, `is-uecl`, `is-relegation`. |
| `…`         | `span props` | Passed through.                                                          |

## Do

- Always next to the band's name.

## Don't

- Don't use a band colour for anything but its competition.

[preview.html](preview.html) renders it from the bundle.
