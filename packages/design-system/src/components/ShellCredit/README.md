# ShellCredit

The family credit at the foot of every page: made by pearpages, and the build.

```tsx
import { ShellCredit } from '@fm/design-system'
```

## Props

| Prop         | Type     |                                 |
| ------------ | -------- | ------------------------------- |
| `madeBy`     | `string` | "Made by", translated.          |
| `buildLabel` | `string` | The tooltip on the build stamp. |
| `commit`     | `string` | The build.                      |
| `iconSrc`    | `string` | The pearpages mark.             |
