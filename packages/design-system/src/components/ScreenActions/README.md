# ScreenActions

A row of buttons at the foot of a screen block.

```tsx
import { ScreenActions } from '@fm/design-system'
```

## Props

| Prop        | Type        |                 |
| ----------- | ----------- | --------------- |
| `className` | `string`    | Extra classes.  |
| `…`         | `div props` | Passed through. |

## Do

- Put the primary action last.

## Don't

- Don't use it for navigation between screens; that is the footer's job.

[preview.html](preview.html) renders it from the bundle.
