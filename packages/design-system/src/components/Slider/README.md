# Slider

A range control, styled to the panel.

```tsx
import { Slider } from '@fm/design-system'
```

## Props

| Prop | Type          |                                             |
| ---- | ------------- | ------------------------------------------- |
| `…`  | `input props` | Pass `type="range"`, `min`, `max`, `value`. |

## Do

- Show the value beside it.

## Don't

- Don't use a slider whose best setting is an end stop (P10).

[preview.html](preview.html) renders it from the bundle.
