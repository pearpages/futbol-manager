# StatLabel

The label of a stat.

```tsx
import { StatLabel } from '@fm/design-system'
```

## Props

| Prop | Type             |                                                          |
| ---- | ---------------- | -------------------------------------------------------- |
| `as` | `'span' \| 'dt'` | Element. Default `span`; `dt` inside a description list. |
| `…`  | `span props`     | Passed through.                                          |
