# FieldLabel

The small uppercase label of a field.

```tsx
import { FieldLabel } from '@fm/design-system'
```

## Props

| Prop | Type                |                           |
| ---- | ------------------- | ------------------------- |
| `as` | `'label' \| 'span'` | Element. Default `label`. |
| `…`  | `label props`       | `htmlFor` included.       |

## Do

- Point `htmlFor` at the control.

## Don't

- Don't write it in capitals; the style uppercases it.

[preview.html](preview.html) renders it from the bundle.
