# StadiumView

The club's ground, drawn at its capacity.

```tsx
import { StadiumView } from '@fm/design-system'
```

## Props

| Prop    | Type     |                                          |
| ------- | -------- | ---------------------------------------- |
| `src`   | `string` | The drawing.                             |
| `seats` | `string` | The capacity rung, which sets its scale. |

## Do

- Pick the drawing by capacity.

[preview.html](preview.html) renders it from the bundle.
