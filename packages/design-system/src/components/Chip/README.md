# Chip

A small position tag: POR, DEF, MIG, DAV.

```tsx
import { Chip } from '@fm/design-system'
```

## Props

| Prop        | Type         |                                                      |
| ----------- | ------------ | ---------------------------------------------------- |
| `className` | `string`     | `is-gk`, `is-df`, `is-mf` or `is-fw` picks the tone. |
| `…`         | `span props` | Passed through.                                      |

## Variants

- `is-gk`, `is-df`, `is-mf`, `is-fw`.

## Do

- Use it beside a player's name.

## Don't

- Don't use it for anything but a position.
