# Hint

A small line of help under a control or a block.

```tsx
import { Hint } from '@fm/design-system'
```

## Props

| Prop        | Type      |                 |
| ----------- | --------- | --------------- |
| `className` | `string`  | Extra classes.  |
| `…`         | `p props` | Passed through. |

## Do

- Keep it to one or two lines.

## Don't

- Don't hide a rule the player needs in a hint; put it in a note.
