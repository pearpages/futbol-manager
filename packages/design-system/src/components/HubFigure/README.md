# HubFigure

One painted figure, at the foot of a hub quadrant.

```tsx
import { HubFigure } from '@fm/design-system'
```

## Props

| Prop     | Type     |                                  |
| -------- | -------- | -------------------------------- |
| `figure` | `string` | Which figure, for `data-figure`. |
| `src`    | `string` | The cut-out image.               |

## Do

- Use the cut-outs in `assets/Images`.

## Don't

- Don't stretch it; it keeps its own width.

[preview.html](preview.html) renders it from the bundle.
