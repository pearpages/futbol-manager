# ScreenNote

A sentence of explanation inside a screen, in the soft screen ink.

```tsx
import { ScreenNote } from '@fm/design-system'
```

## Props

| Prop        | Type      |                           |
| ----------- | --------- | ------------------------- |
| `className` | `string`  | `is-out` dims it further. |
| `…`         | `p props` | Passed through.           |

## Variants

- `is-out`: a note about something that no longer applies.

## Do

- Write whole sentences; every string comes from the app's dictionaries.

## Don't

- Don't use it for errors; a refusal gets its own class in the screen.
