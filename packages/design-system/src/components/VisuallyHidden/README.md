# VisuallyHidden

Text for screen readers only.

```tsx
import { VisuallyHidden } from '@fm/design-system'
```

## Props

| Prop | Type         |                 |
| ---- | ------------ | --------------- |
| `…`  | `span props` | Passed through. |

## Do

- Give it its own leading space when it sits inside other text: `CanteraM7` shipped once.

## Don't

- Don't hide something a sighted player also needs.

[preview.html](preview.html) renders it from the bundle.
